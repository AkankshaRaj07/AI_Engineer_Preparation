# AI Engineer Preparation

A hands-on learning repository documenting my journey toward becoming an AI Engineer—from core Python and ML fundamentals to Large Language Models, RAG, and production agentic systems.

## Learning Roadmap

- [ ] **Python Engineering** (`python/`) — Core syntax, data structures, OOP, advanced Python, and async programming
- [ ] **Machine Learning** (`machine-learning/`) — Supervised/unsupervised algorithms, feature engineering, and model evaluation
- [ ] **Deep Learning** (`deep-learning/`) — Neural networks, PyTorch fundamentals, backpropagation, and architectures
- [ ] **LLM Fundamentals** (`llm/`) — Tokenization, embeddings, prompting, fine-tuning, and API integrations
- [ ] **Retrieval-Augmented Generation** (`rag/`) — Vector databases, chunking strategies, hybrid search, and evaluation
- [ ] **Agentic AI** (`agentic-ai/`) — Tool calling, multi-step reasoning, memory, and agent orchestration
- [ ] **FastAPI & Deployment** (`fastapi/`) — Serving ML/AI models, async REST APIs, and containerization
